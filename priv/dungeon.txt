start lobby
fact console.dormant
fact escape.open false

room lobby
  You are in the neglected lobby of what appears to have once
  been a respectable computer science department.
  A faded sign reads:
  ABANDON ALL FRAMEWORKS, YE WHO ENTER HERE.
  A sealed box bears the label: BUGS (ALLEGEDLY CONTAINED).
  A corridor leads north.
  north corridor
end

object box_of_bugs
  name box of bugs
  description The box hums faintly and should probably remain closed.
  at lobby
  fixed
end

room corridor
  You are in a poorly illuminated corridor. The carpet has a
  repeating pattern that may or may not terminate.
  The lobby is south. A red door is east.
  south lobby
  east ruby_room
end

room ruby_room
  Everything here is {slightly too elegant|a little too polished}. A small red gemstone
  rests on a pedestal.
  The corridor is west. A dubious staircase leads north.
  west corridor
  north segvault if carrying.ruby
end

room segvault
  You stand before THE SEGVAULT. It hums with the smug certainty
  of a memory error that has not happened yet.
  {?console.dormant:A black console has a suspiciously ruby-shaped socket.|The console now glows with a ruby-red certainty.}
  The staircase is south.
  south ruby_room
  north escape if escape.open
end

room escape
  Cold night air arrives with the confidence of a process that has
  finally received SIGTERM. A fire door leads out of the department.
  south segvault
end

object ruby
  name ruby
  description The ruby is red enough to make a point of it.
  at ruby_room
  portable
end

object pedestal
  name pedestal
  description The pedestal is far too elegant to be portable.
  at ruby_room
  fixed
end

object fire_door
  name fire door
  description The fire door has a reassuringly ordinary push bar.
  at escape
  fixed
end

action open box of bugs
  require here.box_of_bugs
  say The label promises this is completely safe.
  bug box_of_bugs
end

action use ruby on console
  require carrying.ruby
  say The ruby fits the socket. Somewhere, a machine sounds less dormant.
  clear console.dormant
  set escape.open
end

action leave through fire door
  require here.fire_door
  say You push through the fire door and escape before anyone can explain the Segvault.
  win
end

event segvault_arrival
  on enter segvault
  once
  say A distant pager chirps. The Segvault pretends not to notice.
end
